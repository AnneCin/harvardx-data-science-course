# HarvardX Data Science Professional Certificate

Solutions and notes for the HarvardX / edX Data Science 
Professional Certificate program, completed in R.

## Background

I'm an architect and computational design specialist with 
experience in parametric design, BIM, and Design-to-Production 
workflows (Rhino/Grasshopper, Revit/Dynamo). This certificate 
is part of my transition toward data-driven approaches in the 
AEC industry — bridging generative design tooling with 
statistical reasoning and machine learning.

## Modules

R · tidyverse · ggplot2 · caret · R Markdown
