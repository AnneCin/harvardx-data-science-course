# Architectural Data Projects

This directory contains my personal computational design projects, where I bridge the gap between architectural practice and data science.

## Projects

- **Cologne Playground Analysis**: Spatial analysis of public playground infrastructure in Cologne.
    - **Goal**: Evaluate equipment quality and accessibility based on urban location data.
    - **Tools**: `sf` (geospatial data), `tidyverse`, `ggplot2`.

- **Generative Facade Optimization**: Parametric design study.
    - **Goal**: Using Monte Carlo simulations to optimize facade louver angles for energy efficiency.
    - **Export**: Generates performance datasets for downstream Rhino/Grasshopper workflows (`data/rhino_facade_data.csv`).

- **Data Pipeline Template**:
    - **Purpose**: A reusable workflow template for importing, cleaning, and visualizing architectural datasets.

## Methodology
My approach focuses on creating reproducible workflows. By treating architectural parameters as data, I aim to move from intuitive design to evidence-based decision-making.
